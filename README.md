# СОЮЗ—ПЕРМЬ — независимая демонстрация сайта

Персонализированный статический сайт с отдельными направлениями «Натяжные потолки» и «Корпусная мебель», портфолио по опубликованным материалам и двумя интерактивными конструкторами.

**Важно:** проект — не официальный сайт компании. Все изображения — авторские SVG-иллюстрации. Они не являются фотографиями реализованных заказов; для коммерческого запуска требуется разрешение на реальные материалы.

## Размещение на Vercel

1. Распакуйте ZIP, загрузите **содержимое** архива в корень GitHub-репозитория.
2. Импортируйте репозиторий в Vercel, установите **Framework Preset: Other**.
3. Не задавайте команду сборки. Output directory — корень `.`.
4. Выполните Deploy. `index.html` — входная страница, остальные файлы открываются по соответствующим адресам `.html`.

Зависимости, `npm`, сервер, база данных и API-ключи не нужны.

`robots.txt`, `meta robots` и заголовок `X-Robots-Tag` через `vercel.json` закрывают демоверсию от индексации. Перед публикацией *официального согласованного сайта* следует убрать эти ограничения, добавить принадлежащий компании домен и заменить демонстрационные иллюстрации настоящими разрешёнными изображениями.
